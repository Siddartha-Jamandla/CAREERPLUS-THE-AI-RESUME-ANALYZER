## ✨ Comprehensive Feature Matrix

### 📄 1. AI Resume Analysis & Optimization
* **Recruiter ATS Scoring**: Multi-dimensional scoring evaluating impact, keyword matching, hard/soft skills, structural parseability, and conciseness.
* **Metric & STAR Bullet Point Studio**: Rewrites passive bullet points into quantified, achievement-oriented statements with measurable results.
* **ATS Compatibility & Format Safety**: Scans layouts for parser compatibility, font standardization, column safety, and metadata sanitization.
* **Interactive Drag-and-Drop Resume Builder**: Visual resume editor with live reordering, instant metric enhancement, and pixel-perfect PDF export.

### 💼 2. Jobs, Internships & Upskilling Hub
* **Project Ideas Hub (Guaranteed 10+ Tailored Ideas)**: High-impact portfolio project suggestions complete with system architecture blueprints, GitHub repository starter code, and copyable resume bullets.
* **100% Genuine Live Internships**: Active hiring opportunities from tier-1 tech firms (Google, Microsoft, Meta, Apple, Stripe, OpenAI, Uber, Amazon) with verified stipend data ($50–$75/hr or monthly) and PPO conversion pathways.
* **Verified Free Certified Courses**: 100% free courses with recognized certifications (freeCodeCamp, Harvard CS50, Stanford Online, Google Cloud) directly addressing missing resume skills.
* **Genuine Live Job Portals**: Filtered active job openings matching candidate experience level and tech stack.
* **Skill Progression Roadmaps**: Milestone-by-milestone upskilling roadmaps for closing critical technical competencies.

### 🎙️ 3. Live AI Mock Interview Simulations
* **Voice & Video AI Interviewer**: Real-time multi-modal mock interview practice with live transcriptions, speech cadence tracking, and video facial feedback.
* **AI Voice Audio Room**: Speech-to-speech mock interview simulations assessing technical correctness, depth of answers, and communication clarity.
* **Hiring Manager Assessment Scorecard**: Recruiter rubric breaking down behavioral responses, system design depth, red flags, and hiring recommendations.
* **Technical Flashcard Drills**: Quick-fire interactive flashcard drills across Algorithms, System Design, Cloud Architecture, and DevOps.

### 🚀 4. Career Accelerators & Content Studios
* **Tailored Cover Letter Generator**: Generates custom, job-description-matched cover letters formatted in multiple professional tones.
* **LinkedIn Profile & Post Optimizer**: Optimizes profile headlines, summaries, and produces viral engineering thought-leadership posts.
* **AI Web Portfolio Generator**: Builds a live, hosted web portfolio showcase in 1 click from parsed resume data.
* **Interactive Kanban Job Tracker**: Visual CRM board for tracking job applications across Applied, Screening, Interviewing, Offer, and Rejected stages.
* **Salary & Offer Equity Evaluator**: Level-adjusted total compensation calculator with negotiation strategy scripts.
* **24/7 AI Career Coach Chat**: Real-time conversational AI mentor for career transitions, salary negotiations, and technical guidance.

### 🛡️ 5. Real-Time Telemetry & Visitor Tracking
* **Live Visitor Tracker**: Real-time session monitoring with IP telemetry, geolocation detection, active device logging, and route analytics.
* **Admin Control Center**: Comprehensive dashboard for user management, rate limiting, audit logs, and traffic insights.
* **Security & Multi-Factor Auth (MFA)**: Secure JWT session management, SSO integration, OTP verification, and role-based access control.

## 🚀 Getting Started & Local Development

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher
* **Gemini API Key**: Obtain a key from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/siddarthajamandla-sketch/career-plus.git
cd career-plus
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY=your_google_gemini_api_key_here
```

### 4. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your web browser.

### 5. Build for Production
```bash
npm run build
npm start
```
