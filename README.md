## 🌟 About CAREER PLUS+

**CAREER PLUS+** is an end-to-end, full-stack AI career intelligence platform designed to level the hiring field for job seekers, software engineers, and ambitious professionals worldwide. By combining recruiter-grade resume analysis, real-time voice & video mock interviews, interactive portfolio generation, and personalized career roadmaps, CAREER PLUS+ empowers candidates to convert application gaps into competitive hiring advantages.

## ✨ Key Features & Modules

### 📄 Resume & Profile AI
1. **ATS Resume Analyzer**: Sub-50ms multi-dimensional resume parsing, candidate match scoring, and missing keyword gap analysis.
2. **Interactive Resume Builder**: Real-time drag-and-drop resume editor with instant section generation and PDF export.
3. **Bullet Point Metric Enhancer**: Rewrite bullet points using the **STAR format** with quantified metrics and high-impact action verbs.
4. **ATS Formatting Studio**: Parseability validation, font scanner, and layout safety inspection.
5. **Tailored Cover Letter Generator**: Custom, job-description-matched executive cover letters.
6. **AI Web Portfolio Generator**: Build and host a live interactive web portfolio in 1 click.
7. **LinkedIn Profile Optimizer**: AI-driven profile headline, summary, and work history audit.

### 🎙️ Live Interview & Network Hub
8. **Live Voice & Video AI Mock Interview Studio**: Real-time speech evaluation, tone analysis, posture feedback, and hiring scorecards.
9. **AI Voice Mock Interview Room**: Speech-to-speech audio mock interview practice with live transcriptions.
10. **Hiring Manager Assessment**: Detailed recruiter scorecard with strength-weakness breakdowns.
11. **Technical Flashcard Drills**: Interactive technical interview drills covering system design, algorithms, and CS fundamentals.
12. **Alumni & Peer Network**: Connect with verified job candidates, peer reviewers, and industry mentors.

### 📈 Career Growth & Tools
13. **Career Pathway Roadmap**: 3-year promotion blueprint with skill milestone tracking.
14. **Salary Benchmark Estimator**: Location and level-adjusted compensation analysis with negotiation scripts.
15. **Offer & Equity Evaluator**: Total compensation tool evaluating base salary, equity options, bonuses, and perks.
16. **Candidate Job Tracker CRM**: Kanban board CRM for tracking job application stages, interviews, and deadlines.
17. **Jobs & Upskill Projects**: Personalized job recommendations and resume-worthy portfolio project ideas.
18. **24/7 AI Career Coach Chatbot**: Real-time conversational AI mentor for career advice.

## 🛠️ Tech Stack & Architecture

* **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React Icons, Recharts (Data Visualization), Canvas Confetti.
* **Backend**: Node.js, Express, TSX, Esbuild (bundled to CommonJS `dist/server.cjs`).
* **AI Integration**: Google Gemini API (`@google/genai` SDK) via secure server-side proxy routes.
* **Storage & Auth**: Local state persistence, session security, and admin user dashboard.

## 🚀 Getting Started

### Prerequisites
* **Node.js**: v18 or higher
* **npm**: v9 or higher
* **Gemini API Key**: Obtain a key from [Google AI Studio](https://aistudio.google.com/)

### Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/siddarthajamandla-sketch/career-plus.git
   cd career-plus
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.
